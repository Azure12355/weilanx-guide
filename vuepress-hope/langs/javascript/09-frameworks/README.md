# 框架与库

现代前端开发离不开框架和库的支持。

## 学习内容

- [React](./react.md) - 组件、Hooks、状态管理
- [Vue](./vue.md) - 响应式、组件、路由
- [Angular](./angular.md) - 依赖注入、指令、服务
- [UI 组件库](./ui-libraries.md) - Material-UI、Ant Design、Element Plus

## 框架对比

| 特性 | React | Vue | Angular |
|------|-------|-----|--------|
| 学习曲线 | 中等 | 较低 | 较高 |
| 状态管理 | Redux、MobX | Vuex、Pinia | RxJS、NgRx |
| 组件风格 | JSX | 模板语法 | 模板语法 |
| 适用场景 | 大型应用 | 快速开发 | 企业应用 |

::: tip 框架选择建议

- **初学者**：Vue - 文档清晰，上手简单
- **大型应用**：React - 生态丰富，灵活性强
- **企业级**：Angular - 架构完整，类型安全
:::
