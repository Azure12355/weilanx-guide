# Java

![Java](https://img.shields.io/badge/Java-17-orange?style=flat-square&logo=openjdk)
![JVM](https://img.shields.io/badge/JVM-HotSpot-red?style=flat-square)

## 概述

Java 是一门面向对象的编程语言，由 Sun Microsystems（现 Oracle）于 1995 年发布。它的设计哲学是"一次编写，到处运行"（Write Once, Run Anywhere）。

## 核心特点

<uly>
<li><strong>跨平台</strong>：通过 JVM 实现平台无关性</li>
<li><strong>面向对象</strong>：纯面向对象设计，支持封装、继承、多态</li>
<li><strong>自动内存管理</strong>：垃圾回收机制（GC）自动管理内存</li>
<li><strong>强类型</strong>：编译时类型检查，减少运行时错误</li>
<li><strong>多线程</strong>：内置对并发编程的支持</li>
</uly>

## 学习路径

1. **Java 基础** → 语法、OOP、集合、IO
2. **Java 进阶** → 反射、注解、泛型、NIO
3. **JUC 并发** → 线程、锁、并发工具类
4. **JVM 虚拟机** → 内存模型、GC、类加载、性能调优
