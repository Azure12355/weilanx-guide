# 基础语法

掌握 JavaScript 的基础语法是成为合格开发者的第一步。

## 学习内容

- [变量与声明](./variables.md) - var、let、const
- [运算符](./operators.md) - 算术、比较、逻辑运算符
- [流程控制](./control-flow.md) - 条件语句、switch
- [循环结构](./loops.md) - for、while、for...of

## 代码示例

```javascript
// 变量声明
let name = "JavaScript";
const version = 6;

// 流程控制
if (version >= 6) {
    console.log(`${name} ES${version}+`);
}

// 循环
for (let i = 0; i < 5; i++) {
    console.log(i);
}
```
