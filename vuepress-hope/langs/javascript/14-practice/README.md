## 项目技术栈

| 项目 | 前端框架 | 状态管理 | 后端技术 | 特色功能 |
|------|----------|----------|----------|----------|
| 待办事项 | Vue 3 | Pinia | LocalStorage | 拖拽排序 |
| 天气应用 | React | Hooks | Axios API | 响应式设计 |
| 聊天应用 | Vanilla JS | WebSocket | Node.js + Socket.io | 实时消息 |

::: tip 项目建议

1. **由简入繁**：从简单功能开始
2. **关注代码质量**：模块化、可维护性
3. **学习最佳实践**：遵循项目规范
4. **部署上线**：使用 Vercel/Netlify 部署
:::
