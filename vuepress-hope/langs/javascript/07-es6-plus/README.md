# ES6+ 新特性

ES6（ES2015）是 JavaScript 的一次重大更新，后续版本持续引入新特性。

## 学习内容

- [let 与 const](./let-const.md) - 块级作用域、暂时性死区
- [模板字符串](./template-literals.md) - 字符串插值、多行字符串
- [解构赋值](./destructuring.md) - 数组解构、对象解构
- [展开与剩余](./spread-rest.md) - 展开运算符、剩余参数
- [模块化](./modules.md) - import/export、模块系统
- [Symbol](./symbols.md) - 唯一值类型、Symbol 属性
- [ES2023+](./es2023-plus.md) - 最新特性跟踪

## ES 版本对应

| 版本 | 年份 | 主要特性 |
|------|------|----------|
| ES5 | 2009 | 严格模式、JSON |
| ES6/ES2015 | 2015 | let/const、箭头函数、class、Promise |
| ES2017 | 2017 | async/await、Object.values |
| ES2020 | 2020 | 可选链、空值合并 |
| ES2022 | 2022 | 顶层 await、类字段 |
| ES2023+ | 2023+ | 新数组方法、Symbol 作为 WeakMap 键 |
