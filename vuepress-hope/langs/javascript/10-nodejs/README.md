# Node.js 开发

Node.js 使 JavaScript 可以运行在服务器端，实现了全栈 JavaScript 开发。

## 学习内容

- [Node.js 基础](./node-basics.md) - REPL、全局对象、模块系统
- [模块系统](./modules.md) - CommonJS、ES Modules
- [文件操作](./file-system.md) - fs 模块、路径操作
- [HTTP 服务器](./http-server.md) - http/https 模块、Express
- [NPM 包开发](./npm-package.md) - 包发布、CLI 工具

## Node.js 应用场景

::: tip 适用场景

1. **Web 服务器**：Express、Koa、Fastify
2. **工具链**：Webpack、Vite、ESLint
3. **桌面应用**：Electron、Tauri
4. **命令行工具**：CLI 脚本、自动化工具
5. **微服务**：NestJS、Micro 服务架构
:::
